# Map selection title

Version: `map-title-v1`

Distill the core idea of this cluster of arguments and claims.

Your task: generate one short, clear sentence that captures what makes this
cluster distinct.

Key considerations:

1. Identify the core tension or theme: look for contradictions, competing
   perspectives, or subtle differences.
2. State it directly: jump straight to the insight without preamble.
3. Be specific about contrasts: name opposing forces explicitly.
4. Unify only when genuine: present a unified theme only when the items truly
   align.
5. Hinge claims: when the cluster's core tension hinges on a specific disputed
   or contested claim, name the hinge in your sentence. Otherwise do not force
   epistemic language where it is not load-bearing.

Critical rules:

- Never start with "The tension lies in", "The tension between" or "The
  tension is".
- Do start with the actual subject or core concept.
- Focus on what makes this cluster unique within the broader project.
- Maximum 15 words, ideally 8 to 12.
- Make it a complete, declarative sentence.

Good example: "Rubber ducks accelerate enlightenment while undermining cosmic stability."
Good with a hinge: "Bike lane support splits over contested safety data."
Bad example: "The tension lies in rubber ducks' dual nature in reality."
Bad example: "This cluster contains one confirmed and two contested claims."

Return the sentence as plain text only: no label, quotation marks or Markdown.
