# Library & analysis

The library was removed in dembrane v3. There are no views and no aspects any more, and no
library to generate. The project sidebar has no "Library" entry. If an old link or an old
guide sent you here, use the table below.

| You used the library to | Use this now |
|---|---|
| See what people argue, with the quotes behind it | [Map](./argument-map.md) (Beta): the arguments in a project, with related arguments close together. |
| Show a room what came up | [Present](./present.md) (Beta): popcorn, "Tensions", "Map" and "Stakeholders" on a room screen. |
| Check a result, reword it or take it out | [Analysis](./analysis.md): every finding with its evidence and its history. |
| Dig into one question | [Chat & Ask](./chat-and-ask.md): ask about the conversations you select. |
| Share a written summary | [Reports](./reports.md): one article from the project's conversations. |

## What needs a plan

The old library needed a paid plan. Map, Present, popcorn, canvases and Analysis need none.
Three things in this area do:

- The public page of a presentation needs the Innovator plan or higher.
- Taking the "made with dembrane" mark off the room screen needs the Changemaker plan or
  higher.
- "Automation" (Beta), the project's webhooks, needs the Changemaker plan or higher.

See [tiers & billing](./tiers-and-billing.md).

## The word "Library" today

One page still carries the name. "Library" now lists a project's
[canvases](./canvas.md). It is not in the sidebar. You reach it from a card in an assistant
chat.
