# For hosts

You are a host when you set up a project, invite people to speak, and work with what they
said. New here? Start with [getting started](./getting-started.md). It takes you from
sign-up to your first transcript.

You do not need to be technical. If you can run a meeting, you can host a dembrane project.
And remember what the tools are for: summaries, answers and reports point you to what is
worth reading. The judgement stays with you and the people in the room.

## What your role lets you do

| You want to | Admin | Member | External | Observer |
|---|---|---|---|---|
| Read projects, conversations and reports | yes | yes | yes | yes |
| Edit project settings and the portal, upload audio, edit and tag conversations | yes | yes | yes | no |
| Use Ask and generate reports | yes | yes | yes | no |
| Create or clone a project, delete a conversation | yes | yes | no | no |
| Delete or move a project, make a project private, invite people | yes | no | no | no |

The "Billing" role sees usage and invoices and has no access to projects. The full table is
in [roles & permissions](../../features/roles-and-permissions.md).
